Build a demo web app called "TenderMind AI — Intelligent Procurement Evaluation Platform" for a hackathon demo. This is a DEMO ONLY — everything runs in the browser with Claude API for intelligence. No real backend, no real OCR, no database.

## STACK
- Single HTML file with vanilla JS + CSS (zero build step, runs instantly on Replit)
- Anthropic Claude API called directly from browser fetch()
- All state in-memory (JavaScript objects)
- No external dependencies except Google Fonts

---

Professional government dashboard aesthetic:
- Color palette: Deep navy #0A1628 (background), White #FFFFFF (cards), Government blue #1B4F8A (primary), Amber #F59E0B (warnings/flags), Green #10B981 (pass), Red #EF4444 (fail), Gray #6B7280 (neutral)

## APP STRUCTURE

Four sequential stages shown as a progress stepper at the top:
1. Tender Upload → 2. Criteria Review & Approval → 3. Bidder Evaluation → 4. Final Report

  - Department: Central Reserve Police Force
  - Category: Civil Construction Services  
  - Submission Deadline: 15 June 2024
  - Estimated Value: ₹12.5 Crore

The demo tender content (hardcode this, do NOT call Claude for this — it's instant):

2. EXPERIENCE: Minimum 3 similar construction projects completed in last 5 years, each valued ≥ ₹1 Crore (Mandatory)

## CLAUDE API USAGE

Only call Claude API for ONE thing — the qualitative criterion reasoning for Criterion 2 (similar projects).

When evaluating any bidder's Criterion 2, call Claude with:

System prompt:
"You are a government procurement evaluation AI. Evaluate whether the bidder's project experience meets the tender criterion. Be specific, cite the project descriptions, and give a clear recommendation. Respond in 3-4 sentences maximum. End with: RECOMMENDATION: COMPLIANT or RECOMMENDATION: NON-COMPLIANT or RECOMMENDATION: REQUIRES HUMAN REVIEW"

User message:
"Tender Criterion: Minimum 3 similar construction projects completed in last 5 years, each valued at minimum ₹1 Crore.

Bidder's declared projects:
1. Construction of 24 staff quarters, CISF Camp Ghaziabad — Completed March 2023 — Value: ₹2.3 Crore
2. Renovation of 3 government office buildings, PWD Delhi — Completed August 2022 — Value: ₹1.8 Crore  
3. Construction of boundary wall and guardpost, BSF Camp — Completed January 2021 — Value: ₹0.9 Crore

Does this bidder meet the criterion? Reason carefully about project similarity and value thresholds."

Show a "AI is reasoning about project similarity..." loading state (1.5 seconds) then display Claude's response in a styled reasoning card with the recommendation badge.

6. The app should work entirely without the Claude API key — all demo data is hardcoded, Claude only enhances the qualitative reasoning display
7. Make the confidence bars animate on load — they should fill from 0 to their final value over 800ms
